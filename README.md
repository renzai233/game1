# 晶核防线 Demo

这是从 Cocos Creator 3.8.8 项目导出的 `web-mobile` 静态 Demo 包，可直接用于 Cloudflare Pages。

## Cloudflare Pages

- Build command: 留空
- Build output directory: `/`
- Root directory: 仓库根目录

## 本地预览

在本目录启动静态服务器：

```bash
python3 -m http.server 8788
```

然后打开：

```text
http://127.0.0.1:8788/
```
